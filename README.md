# Glrec — Portfólio de Projetos & Estudos

Bem-vindo(a) ao repositório **Glrec**! Esta pasta centraliza diversos projetos, exercícios e aplicações desenvolvidas ao longo da minha trajetória de estudos e cursos técnicos.

---

##  Sobre a Pasta

Cada subpasta neste repositório representa um projeto individual ou módulo de estudo. Para facilitar a navegação e o entendimento, **cada projeto possui o seu próprio arquivo `README.md` dedicado**, contendo:

-  **Propósito:** O objetivo e o contexto do projeto.
-  **Tecnologias Utilizadas:** Linguagens, frameworks, bibliotecas e ferramentas aplicadas.
-  **Como Usar:** Instruções passo a passo para execução e testes locais.
